# PGDT Experimental Dataset

## Overview
This dataset supports research on Pedagogically
Guided Decision Trees (PGDT) for explainable
competency assessment in engineering education.

## Dataset Information
- Format: CSV
- Features: 23 input variables
- Target: competency_label
- Data type: Experimental research data

## Target Variable
competency_label:
- Low
- Moderate
- High

## Research Application
The dataset is intended for:
- Machine learning experiments
- Explainable AI
- Decision tree classification
- Engineering competency assessment

## Data Format
The dataset is provided in CSV format.
